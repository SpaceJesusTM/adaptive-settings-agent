## 3. Summary Across Both Games

- **Fully implemented canonical behavior:** Core VALORANT Video/Map/UI/Voice menus and CS2 Video Presets, Game, Audio, and Crosshair/Scopes pixel styles with exact verified labels, options, dependencies, and CS2 explicit `Apply Changes` isolation.
- **Documented simulated approximations (transparently labelled in UI and data):** VALORANT Crosshair/Controls/Stats/Voice-Over ranges marked `rangeVerified: false` or `secondary-only`; CS2 `HudEdgeX` fixed `0.50` minimum floor; simulated GPU/Monitor/Audio device option lists (`nvidia_pc`/`amd_pc` scenarios); CS2 `New` tab curated from Sept/Oct 2026 updates.
- **Deliberately unsupported controls:** VALORANT in-match tab; CS2 Controller / Steam Input & chat-wheel phrase editor; real game config file writes and live FPS benchmarking.
