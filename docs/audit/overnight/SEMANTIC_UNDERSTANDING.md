# Understanding intent in the settings menu

GamePlan needs to tell apart the player's current objective, the cost they accept, requirements to keep unchanged, a question about a setting, and a request to remember something. This separation is shared by the planner, review validation and Discover. The model can suggest values and reasoning. Catalogue validation and explicit Apply determine what can be committed. Durable memory still requires direct evidence from the player. | Path | What it contributes | Observed weakness |
| --- | --- | --- |
| Deterministic clause handling and exact execution | Recognizes labelled controls, simple recovery, session-versus-durable intent and certain statements that accept a cost for a benefit. One mixed turn can produce a recommendation, explanation and explicitly requested scoped memory. | Needs recognizable syntax and catalogue labels. Both implicit visual requests lack a dependable default route. |
| Compact composition | Selects ordinal candidates from the feasible catalogue and lets the server reconstruct exact recommendations and grounded rationales. | Can omit good candidates, propose none despite persuasive prose, or require an expensive repair. It does not add a separate intent stage. |
| Optional semantic interpretation plus shared composition | Runs a small structured interpretation call for unclear consequential requests. It passes interpreted objective dimensions into coverage and lets known constraints and canonical validation stay authoritative. | A structurally sound response can confuse an advice request with explanation, ask an unnecessary question or miss the evidence binding. Earlier variants failed to turn implicit visual terminology into applicable options. The final guarded variant improves the two tested visual cases. |

## Generalization and boundaries

The first audit treated accepted frame-rate loss as a performance goal on the visibility fixture, and staged a change to protected MSAA. The overnight parser identifies the accepted cost in a limited family of trade-off constructions. It scores the positive outcome, preserves named constraints and keeps the request text inspectable. The runtime handles literal temporal values and narrowly scoped restoration before broader composition. A quoted hypothetical mention does not introduce memory. A single unresolved “put that back” remains a clarification.

The independently authored mixed fixture asks for steadier frame rate while preserving resolution and anti-aliasing, an explanation of Ambient Occlusion, and remembering visibility ahead of graphics quality. The earlier implementation lost the planning request and did not attach the precise setting. The candidate's fallback and the three live architecture probes meet its four distinct checks. The active goal is performance, the explanation remains attached to the named control, and the durable positive preference is visibility. The earlier frozen mixed probe still records one valid but incompletely staged compact result.

The initial compact, legacy and semantic ablation used the same four broader fixtures. All scored **9/10**. Only the semantic configuration attempted interpretation for the ambiguous visual request. It returned a clarification about external software even though the request was about the in-game menu. The success on visibility or the exact contrastive explanation does not count as evidence for model-based intent extraction, because those cases bypassed that stage. [Live ablation results](evidence/live-matrix.json)

A tightened in-game prompt avoided the external-software question, but three repeats still staged zero appropriate changes. Among its replies were a plausible reference to Texture Quality and a misleading recommendation to lower filtering. Giving the model catalogue examples and named dimensions improved detection of the visual topic, but it still failed to produce usable options in the two visual probes when the proposed evidence phrase could not be verified. A subsequent variant uses server-numbered clauses so the model can point to exact evidence. The initial optional fields were omitted twice. After requiring integer selections, one run offered valid Texture Quality and Anti-Aliasing advice without staging, and the late floor-pattern request staged a single valid Texture Quality change while respecting both exclusions.

The final **737ea17** variant allowed a direct options question to corroborate the model's bound request, while keeping known exclusions in code. Two live repetitions of each visual case passed (**4/4**). The muddy-edges prompt staged High Texture Quality and MSAA 4x in both repeats. The distant-floor prompt consistently staged High Texture Quality. Both left resolution and crosshair unchanged. Matched legacy probes produced no eligible staged changes on either input. The late floor phrasing was added after the first visual diagnosis and used as a regression case during the later iterations. The final gain covers two related VALORANT requests. Evidence for other games, outcome types or natural histories remains limited.

The final semantic turns took 43.3–59.8 seconds on the Mac, with a 48.4-second median and two calls per turn. The matched legacy turns were 48.7 and 51.9 seconds and each needed repair, so these small probes give evidence of improved usefulness and do not establish a general timing advantage. The semantic phase is worth measuring on stronger inference hardware even if the added call costs time. [Per-turn evidence](evidence/live-matrix.json)

The project should continue investigating well-grounded semantic assistance on difficult turns. For the demonstration use legacy mode. Latency is secondary to predicting the appropriate action, applying constraints, and selecting a feasible setting. The model cannot learn a durable preference from acceptance or change guarded values based on a scope guess. The staged experiment permits advice only with a supported request, keeps exclusion checks and runs through the same review and transaction. Use a longer local reasoning budget only if matched outcomes show a meaningful quality gain.
