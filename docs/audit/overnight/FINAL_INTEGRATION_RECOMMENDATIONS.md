The ungrounded interpret-then-compose prompts did not improve staging for implicit visual requests, despite valid JSON. Fixed-order broad prompts and compact ordinals show different failure modes. Catalogued constraints, missing-candidate recall, and user-visible outcome should remain individually measurable in any future design. A useful next model experiment would compare grounded intent extraction to a single combined retrieval and structured-decision pass across settings and games. A useful human experiment would measure independent canonical navigation, explanation, and when players want a behavior-based inference corrected.
